## 3. 可访问性与布局

- 增加“跳到主内容”首个键盘焦点、唯一 `main` landmark、导航展开状态与控制关系。
- 运行记录整行支持 `Enter`/空格选择；笔记和扩展搜索输入具有稳定可访问名称。
- 全局 `focus-visible` 使用更高对比度焦点色；加载、空、部分、错误状态提供读屏语义。
- 1440×1000 页面完成视觉采证；390×844 下无 document 级横向溢出，侧栏降级为图标导航，正文保持可读。

视觉证据位于 `docs/ui8-evidence/`，共 21 张，包括首页、专题、详情四分区、扩展搜索三状态、来源、质量、运行、设置和小屏首页。
