## 1. 阻断项复验

### [P1][已关闭] 辅助接口失败会把整个应用误报为“本地 API 未连接”

启动加载已改为 `Promise.allSettled`：dashboard 继续作为全局核心门禁；sources、experts、runs、feedback、settings 和 configuration-status 独立记录失败。成功内容继续显示，页面顶部明确列出缺失资源；进入受影响的核心页面时显示可重试错误，而不是伪装为空或全局断连。

新增 App 组件测试验证 `/api/runs` 单独失败时，dashboard 仍显示“今日无达标情报”、出现 partial 提示、不会出现“本地 API 未连接”，且运行记录页提供失败原因与重新加载入口。

复验结果：PASS。

### [P1][已关闭] 回收站读取失败被伪装为空态，恢复/永久删除失败没有可见反馈

回收站现已区分 loading、empty、success、error；读取失败显示服务端原因和重新加载入口。恢复及永久删除具有独立 pending 状态和重复提交保护；操作失败显示具体条目与错误原因，并保留原记录供用户再次操作。

新增测试分别覆盖回收站读取失败、恢复失败与永久删除失败；三条失败分支均验证不可伪装为空/成功，写操作失败后条目仍可见。

复验结果：PASS。
